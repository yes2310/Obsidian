**핵심 정리 – GPT(Generative Pre‑trained Transformer) 개요**

| 항목 | 핵심 내용 |
|------|-----------|
| **GPT란?** | OpenAI가 발표한 “Generative Pre‑trained Transformer” 시리즈. 언어 모델을 사전학습(Pre‑training)한 뒤, 다양한 NLP 태스크에 파인튜닝(Fine‑tuning)해 활용. |
| **모델 구조** | Transformer **디코더**를 여러 층(레이어) 쌓은 형태. 입력은 토큰 임베딩 + 세그먼트(문장) 임베딩 + 포지션 임베딩. |
| **학습 방식** | 1. **프리트레이닝** – 무감독(unsupervised)으로 대규모 텍스트 코퍼스에서 “다음 토큰 예측”을 학습. 2. **파인튜닝** – 감독학습(supervised)으로 레이블이 있는 데이터(예: 감정, 분류, 추론 등)를 이용해 특정 태스크에 맞게 재학습. |
| **언어 모델의 핵심** | 주어진 앞 문맥(단어 시퀀스)에서 다음 토큰의 **조건부 확률**을 예측. 파라미터(θ)는 이 확률을 최적화하는 가중치. |
| **GPT 시리즈 차이** | - **GPT‑1**: 1억~1.5억 파라미터, 기본 구조. <br> - **GPT‑2**: 동일 구조, 대용량(수십억 단어) 웹 크롤링 데이터로 프리트레이닝. <br> - **GPT‑3**: 파라미터 수를 10배 이상 확대, 모델 깊이와 차원(embedding size) 모두 크게 증가. <br> - **GPT‑4**: 아직 공개되지 않았으나, 파라미터 수를 줄이고 효율성을 높여 대규모 모델을 분산 실행할 수 있도록 설계될 전망. |
| **특수 버전** | **DialoGPT**: 대화체(챗봇) 데이터로 사전학습된 GPT‑2 파생 모델. 20만 개 대화 문장으로도 0.87 정확도 달성, 대규모 대화 데이터(1억 개)로 성능 향상 가능. |
| **실제 활용** | GPT‑2/3는 높은 성능을 보이나, 파라미터가 많아 단일 서버에서 실행이 어려움 → 분산 컴퓨팅 필요. DialoGPT는 챗봇에 특화돼 있어 파인튜닝만으로도 우수한 대화형 AI를 만들 수 있음. |
| **핵심 포인트** | 1) **언어 모델**은 토큰 예측을 통해 확률 분포를 학습. 2) **프리트레이닝**은 무감독이지만, 모델이 예측한 토큰과 실제 토큰을 비교해 오차를 계산해 역전파 가능. 3) **파인튜닝**은 레이블이 있는 데이터(감정, 분류, 추론 등)를 사용해 태스크별 예측을 수행. 4) GPT‑2/3 차이는 주로 데이터 규모와 파라미터 수이며, GPT‑4는 효율성을 높여 대규모 모델을 분산 실행할 수 있도록 설계될 전망. |

**결론**  
GPT 시리즈는 Transformer 디코더를 깊게 쌓아 언어 모델링을 수행하고, 사전학습과 파인튜닝을 통해 번역, 요약, 감정 분석, 추론, 챗봇 등 다양한 NLP 태스크를 해결한다. GPT‑2/3는 데이터와 파라미터 규모가 크게 증가했지만, 실행 비용과 분산 처리의 어려움이 존재한다. DialoGPT와 같은 대화체 최적화 모델은 챗봇 개발에 유용하며, GPT‑4가 향후 효율성을 개선해 출시될 것으로 기대된다.
