**강의 요약 – GPT(Generative Pre‑Training) 개요**

| 주제 | 핵심 내용 |
|------|-----------|
| **언어 모델(LLM) 개념** | 1) **확률 모델**: 단어 시퀀스 \(x_1,\dots,x_{i-1}\) 주어졌을 때 다음 단어 \(x_i\)의 조건부 확률을 예측. 2) **파라미터(θ)**: 모델 가중치. 3) **마르코프 가정**: 앞뒤 문맥을 한정된 길이(예: n‑gram)로 근사. 4) **셀프‑어텐션**: Transformer에서 각 토큰이 다른 토큰과의 관계를 학습. |
| **BERT vs GPT** | - **BERT**: Encoder‑only, Masked Language Modeling(MLM)으로 프리트레이닝.  <br> - **GPT**: Decoder‑only, Autoregressive Language Modeling(ARLM)으로 프리트레이닝.  <br> - GPT는 왼쪽 문맥만 보므로 BERT보다 문맥 활용이 제한적이지만, 구조가 단순해 학습·배포가 용이. |
| **GPT 시리즈** | 1. **GPT‑1** (2018) – 1B 파라미터, 대용량 웹 데이터로 프리트레이닝. <br> 2. **GPT‑2** – 동일 구조, 크롤링한 40B 토큰 규모 데이터셋 사용. <br> 3. **GPT‑3** – 파라미터 수 175B(≈10‑배 확대), 모델 차원도 크게 증가. <br> 4. **GPT‑4** – 아직 공개되지 않았으나, 파라미터 수와 데이터 규모를 더 줄여 효율성·성능을 동시에 향상시킬 전망. |
| **프리트레이닝 & 파인튜닝** | - **프리트레이닝**: 대규모 텍스트(웹·대화·기타)에서 unsupervised 방식으로 학습. <br> - **파인튜닝**: 특정 태스크(분류, 감정 분석, 추론, 챗봇 등)용 레이블 데이터로 supervised 학습. |
| **다이얼로그 GPT** | GPT‑2를 대화 데이터(≈20만 문장)로 프리트레이닝한 모델. 챗봇용으로 fine‑tune하면 높은 성능(≈0.87 정확도) 달성 가능. |
| **배포·비용 이슈** | GPT‑2/3는 파라미터가 많아 단일 서버에 배포 어려움 → 분산/멀티 GPU 환경 필요. GPT‑4는 효율성을 고려해 파라미터 수를 줄이려는 시도. |

**핵심 포인트 정리**

1. **언어 모델**은 다음 토큰을 예측하는 확률 모델이며, Transformer‑Decoder를 깊게 쌓아 구현된다.  
2. **BERT**는 양방향 문맥을 활용해 MLM으로 학습, **GPT**는 단방향(Autoregressive)으로 학습.  
3. GPT‑1 → GPT‑2 → GPT‑3 차이는 주로 **데이터 규모**와 **모델 파라미터 수**(깊이·너비)이며, 구조 자체는 거의 동일.  
4. **Fine‑tuning** 단계에서는 레이블이 있는 태스크(분류, 추론, 챗봇 등)만으로도 다양한 NLP 문제를 해결 가능.  
5. **다이얼로그 GPT**는 대화 데이터에 특화된 프리트레이닝을 통해 챗봇 성능을 크게 끌어올린 예시.  

이상으로 GPT와 관련된 핵심 개념과 발전 과정을 정리했습니다.
