**핵심 정리 – GPT(Generative Pre‑trained Transformer) 개요**

| 항목 | 핵심 내용 |
|------|-----------|
| **GPT란?** | OpenAI가 발표한 “Generative Pre‑trained Transformer” 시리즈. 언어 모델을 사전 학습(프리트레이닝)하고, 필요에 따라 특정 태스크에 맞게 파인튜닝하는 구조. |
| **입력 구조** | 토큰 임베딩 + 세그먼트(문장) 임베딩 + 포지션 임베딩 → Transformer 디코더(셀프‑어텐션) → 출력 토큰 예측. |
| **프리트레이닝** | *Unsupervised* – 정답 레이블이 없지만, 모델이 스스로 예측한 토큰과 실제 토큰을 비교해 오차를 계산하고 역전파. BERT는 마스킹된 토큰 예측, GPT는 순차적으로 다음 토큰 예측. |
| **파인튜닝** | *Supervised* – 입력 시퀀스와 레이블(예: 감정, 분류, 추론 관계 등)을 주고, 모델이 레이블을 예측하도록 학습. |
| **GPT 시리즈 차이** | - **GPT‑1**: 기본 Transformer 디코더, 1억~1.5억 파라미터. <br> - **GPT‑2**: 동일 알고리즘, 대용량 웹 크롤링 데이터(수십억 토큰)로 프리트레이닝. <br> - **GPT‑3**: 파라미터 수와 모델 차원 대폭 확대(수십억~수백억 파라미터). <br> - **GPT‑4**: 아직 공개되지 않았으나, 파라미터 수를 줄이고 효율성을 높여 대규모 모델을 분산 실행 가능하도록 설계될 전망. |
| **특수 모델** | **DialoGPT**: 대화체 데이터(예: 20만 개 대화 문장)로 프리트레이닝한 GPT‑2 변형. 챗봇용으로 최적화되어 있어 성능이 뛰어남. |
| **실제 활용** | GPT‑2/3은 높은 성능을 보이나, 파라미터가 크고 메모리 요구량이 높아 단일 서버에서 실행이 어려움. 분산 컴퓨팅(여러 GPU/서버) 필요. |
| **핵심 포인트** | 1) GPT는 언어 모델링을 기반으로 다양한 NLP 태스크(분류, 추론, 유사도, 다중 선택 등)를 수행 가능. <br> 2) 프리트레이닝 데이터와 모델 규모가 성능을 좌우하지만, 실행 비용과 효율성도 중요한 고려 요소. <br> 3) DialoGPT 같은 대화체 전용 모델은 챗봇 개발에 유리. |

**요약**  
GPT는 Transformer 디코더를 깊게 쌓아 만든 언어 모델로, 사전 학습 단계에서 대규모 텍스트(또는 대화) 데이터를 이용해 언어 이해와 생성 능력을 획득합니다. 파인튜닝 단계에서는 레이블이 있는 데이터를 통해 특정 태스크(감정 분석, 추론, 분류 등)를 수행하도록 학습합니다. GPT‑2와 GPT‑3는 주로 데이터 규모와 파라미터 수가 증가한 것이 차이이며, GPT‑4는 효율성을 높여 더 작은 모델로도 높은 성능을 목표로 할 것으로 예상됩니다.
